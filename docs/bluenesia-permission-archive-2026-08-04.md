# bluenesia_satin — permission-grant archive (audit item 9)

`docs/font-license-audit-2026-07-31.md` §2 (bluenesia_satin row): *"archive a
copy of the PR #1686 permission grant locally."* This file is that archive,

limitation, both below.**

## Where the permission actually lives

The audit (and the font's own upstream LICENSE file) cite
`github.com/inkstitch/inkstitch/pull/1686`. That PR is titled **"Dinomouse and
NickAinley fonts"** (author `kaalleen`, merged 2022-06-16) — Bluenesia is not
the PR's subject. The permission exchange happens in that PR's **comment
thread, April 2025**, and the grant itself was received via the designer's
website contact form and posted as **screenshots**, not as quotable text.

The font's upstream LICENSE (shipped verbatim as
`src/fonts/bluenesia_satin.LICENSE.txt`) additionally records: the Ink/Stitch
adaptation is by Karen J. Cravens / Silver Seams "with permission", licensed
CC-BY-SA-4.0; the original Bluenesia font by Syafrizal a.k.a. Khurasan is
distributed as "free 100% for personal use and commercial use".
