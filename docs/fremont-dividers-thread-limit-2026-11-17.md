## Why a hairline sews as a satin block

A hairline rule is below what thread covers. Both the engine and the professional
widen it to the narrowest satin column that sews (about 1.1 mm). Changing that
floor is ROADMAP gate 1 (satin width floors need a sew-out) and is not this lane's
to move. Sewing the rule as a run or bean line would be a different construction
from the professional's, with no sew-out showing it reads better on a hat, so it
is not built here.

## What is NOT claimed

Whether a narrower divider crowds the letters less is unknown; the professional's
block is no thinner, so the grader's complaint applies to the professional's file
too. The grader is unproven, so this is a note, not a defect rating.
