## 1. The number to quote

**42.5 / 100** on 15 designs with real customer artwork, chance-corrected,
measured in an isolated worktree. `docs/pro-parity-real-art-2026-08-15.md`.

Three things must travel with it or it will be misread:

- **95 is above the metric's own ceiling.** A pro scores **75-84 against a pro**
  (`selfconsistency.py`). So `42.5/95` is not a 52-point engine deficit. Standing
  ruling in MASTER_SCOPE; target deliberately NOT revised, because n=2.
- **Reconstructed artwork was flattering us by 11.3 points.** Every parity number
  before 2026-08-15 was measured on artwork rebuilt from the pro's own stitches.
- **Measure in a worktree.** Three baselines were invalidated the same day by
  commits landing mid-run. A pinned worktree exists at
  `.claude/worktrees/parity-measure` — keep it for parity work; verify module
  resolution hits the worktree's own `digitizer_core`.

## 2. The four defects, by size

**a. Stage 0 misroutes 10 of 15 real logos into the photo lane.**
`docs/classifier-misroutes-real-logos-2026-08-15.md`. `GRAD_VAR_GRADIENT_MIN =
0.0015` was calibrated on fixtures reading <0.0006; real logos read 0.205-6.135.
Forcing `flat` is worth **+3.2 corpus points** — the largest reachable lever found.
**Blocked**: siting a threshold needs more than one real gradient example.
Spec with four rejected approaches:
`docs/superpowers/specs/2026-08-15-stage0-flat-gradient-recalibration-design.md`.
Test pinning the defect: `digitizer/tests/test_classifier_scale_invariance.py`
(6 passed, 7 xfailed strict).

**b. The garment drives the pro's deviation from artwork.** Beanie vs cap, same
logo: **+45% solidity at flat row spacing**. Hat vs left chest is a null result
because the pro reuses one file for both. `pro-parity-real-art-2026-08-15.md` §5b.
Threading `garment_id` through the harness is worth +0.6 and now done.

**c. The enclosed-background capability already shipped and went unused for
eleven days.** Worth +8.0 per Becker design. Fixed 2026-08-16: the warning now
carries `area_frac` (Becker reports 40%), and alpha-derived holes are marked
`enclosed_colour_unknown` rather than silently inheriting the enclosing thread.
Default deliberately NOT flipped —
`docs/enclosed-background-verdict-2026-08-15.md` §5.

**d. The gradient blend tier never fires on real artwork.** 0 of 26 regions
shaded. `docs/blend-tier-never-fires-2026-08-15.md`. **TABLED** — read that doc's
"ANSWERED" subsection before touching it; `split_tonal_regions` is the chosen route
and its corpus run is recorded there.

## 3. The pattern worth carrying forward

Synthetic references have been flattering this codebase in **four** independent
places:

| component | calibrated on | on real input |
|---|---|---|
| stage 0 flat/gradient gate | fixtures <0.0006 | real logos 0.205-6.135 |
| `stage6_blend` ramp gate | synthetic ramps at r2 = 1.000 | real content ~0.1 |
| pro-parity corpus | artwork rebuilt from pro stitches | flattered 11.3 points |
| `direction` / `sttype` weights | assumed a real 0-1 range | pro-vs-pro ceiling 0.11-0.85 |

Kent's 7 real artworks are the first corrective, and there are only 7. **Getting
more real artwork is the highest-leverage non-code action available**, and it
unblocks (a) directly.

## 5. Instruments added

All under `digitizer/tools/pro_parity/`:

- `real_art.py` — prepares customer artwork. One transform only (uniform-bar crop,
  needed because the Gaulke art is a phone screenshot with black bars). Does NOT
  remove backgrounds, flatten alpha, sharpen or upscale.
- `prep_both.py` — 15 designs, both lanes (reconstructed vs real artwork).
  `PRO_PARITY_GARMENT=0` reproduces pre-2026-08-15 behaviour.
- `artfidelity.py` — `art_iou` / `pro_extra` / `art_missed`: how faithfully the PRO
  reproduced the customer's artwork. Pro-side only, so immune to engine changes.
- `selfconsistency.py` — the scorecard's own ceiling, by scoring the pro against
  themselves. Read its three documented caveats before trusting a number from it.
