# Short satin columns: the pro's centre run, OFF | ON | pro (2026-10-23)

`cfg.satin_underlay_short_columns`, built OFF. Kent's ruling 2026-10-22:
underlay presence is stitch layout, decided from a preview, not a sew-out.
These sheets are that preview. Made by `tools/short_column_underlay.py`
(plans digitized through `tools.pro_pair` at the pro's width and garment,
`hat_front`); the counts are in the PR body.

**How to read them.** The Studio preview and every eye-pairs sheet draw
underlay UNDER the top thread, so underlay is invisible present or absent.
Here every underlay run is drawn OVER the top thread: **red** under a satin
shape (the subject), **orange** under a fill (context). On the pro's panel
red is what `tools/pro_satin_underlay.py` counted as underlay under a satin
column -- his file carries no run kinds, so it is the reader's call, the
same call the PR body's pro percentages rest on. Where his columns overlap
(the MFab silhouette) the reader paints an earlier column's thread too;
read his lettering, not his silhouette.

**Same box.** Ours is cropped to the letter's own stitches plus 2 mm; the
pro's panel is that box as a fraction of his design's extents, with no
registration, so it lands on the same letter give or take a few mm.
