## Laws that still bind

- **1, 9** One satin element = one needle-down run (`R.S`, `R.Z.S` wide); script strokes cross as whole overlapping columns, no junction weld. Constrains `stage6_satin` stroke merge. `play`
- **3** Corners sewn through, not split (1,436 events vs 18 splits); split only past ~90°. `play`
- **4, 21, 41** Satin same-rail density **0.40 mm** — four instruments agree (`SATIN_SPACING_MM = 0.4` correct, no change). ~15% tighter only past 4.5 mm width, above `SATIN_MAX_WIDTH_MM = 5.0`, so inert. Border density is the same 0.40 — no relaxation. `play`, `r3 § Density vs size`, `r3 § Seams`
- **5** Columns run to 5 mm (`SATIN_MAX_WIDTH_MM = 5.0`; browser mirror still 3.0). `play`
- **6** Locks universal and tiny — median **0.45 mm** vs `TIE_STITCH_MM = 0.8`. `play`
- **8, 61, 62** Travel/link run stitch median **2.02 / 1.96 mm** vs `TRAVEL_STITCH_MM`/`UNDERLAY_STITCH_MM = 2.5`; links median 7 stitches. `play`, `chain`
- **11, 13, 14** Border column **1.40 mm** for closed-loop letter outlines, always a closed circuit; bean/triple run at **3 passes / 0.73 mm** is the light-outline tier (`BORDER_WIDTH_MM`, `BEAN_PASSES`, `BEAN_STITCH_MM`). `play`
- **15, 16** No design-wide fill angle (0/8 designs share one at 10°); 45° is not a default (6% at ±7°); angle tracks the region long axis or runs square across it, never unrelated oblique. PCA `principal_angle_deg` already matches; the literal `45.0` stays only as degenerate fallback. `r3 § Fill angle`
- **18** Density does NOT grade with size — pooled ρ(area, gap) = −0.057 over 0–800+ mm². Flat `FILL_ROW_MM` / `SATIN_SPACING_MM` is confirmed correct; do not add size grading. `r3`
- **20** Fill stitch length is a **4.0 mm ceiling with even division per row**, not a target — supersedes law 7's "median ~2.6". `FILL_STITCH_MM = 3.0` → ceiling 4.0; even division is itself a stagger source, recheck `FILL_STAGGERS`. `r3`
- **22** Zigzag underlay gated on width **2.0 mm** (18%→56% across the 1.2–2.0 / 2.0–3.0 boundary) **AND** column length ~**6 mm** — `SATIN_ZIGZAG_ABOVE_MM = 2.5` sits half a bucket high; the length gate does not exist in the engine. `r3 § Underlay recipes`
- **23** Zigzag geometry is constant, not a function of the column: pitch 1.37–1.47 (`SATIN_ZIGZAG_PITCH_MM = 1.45`, shipped 2026-08-05), width 0.82× column (narrowing 0.3→0.09, shipped). `r3`
- **24** Zigzag never sews alone (85–90% paired with a walk); double-Z <1%. Engine already correct. `r3`
- **25** Small lettering (min-dim ≤8 mm) gets one walk and nothing else — walk-only ~68%, zigzag ~7%. Falls out of law 22's gates. `r3`
- **26** Fill underlay is a **running line** (edge run or interior walk, ~62%); lattice is 7 of 507 cases. `fabrics.fill_underlay` `edge_lattice` → `edge_run` (shipped 2026-08-05). `r3`
- **27, 28, 29** Entry at the **free cap**, sewing INTO the junction — 85.2% vs 42.3% for nearest-exit; fair-coin form 86.3%. Class order cap > tee > corner ≈ butt; corner/butt are exits. Worth ≤**10 mm** extra travel (med 5.7), fall back past 20. Partially shipped in `stage6_satin._choose_stroke_entry`; per-end class scoring NOT built (`Stroke` carries only a binary free flag). `r3 § Entry and exit`
- **30** To enter a stroke interior, pros CUT at the crossing — 21.9% of strokes are splits, cut at 0.30 of merged length, 79.3% at a crossing. `SPLIT_SATIN_ABOVE_MM` splits by width only. `r3`
- **32, 33, 36** Sew order is background-to-foreground (77% of 139 overlapping pairs put the smaller later); a design sweeps once in one direction (15/17); inside one colour, one clean pass, travel-optimal. `r3 § Colour sequencing`
- **37, 42** Two fills meet by OVERLAPPING 0.4–0.8 mm and the allowance wanders (2.60 mm p90−p10 inside one seam); `config.overlap_mm` 0.25 → 0.40. The base colour runs CONTINUOUS under the top (med 0.77) — pros do not knock out. `r3 § Seams`
- **39, 40** A seam is usually NOT outlined (6/19 ≥50% coverage; 16% of area fills carry a covering column) — `cfg.border` OFF by default is confirmed. A covering border sits CENTRED: `BORDER_SEAM_OFFSET_MM = 0.0` is now measured (+0.00 n=25 / +0.05 n=41). `r3`
- **16, 17, 18 (phys)** 40wt thread is **0.40 mm** wide = one covering layer; hard floor 0.35, ceiling 0.55. Needle blade 0.75 mm, same-hole radius 0.5 mm. Stitch floors: walk ≥1.5, satin ≥1.0, fill ≥2.0 mm. `phys`
- **22, 23, 24 (phys)** Pull is axial (0.17–0.25 mm loss), push perpendicular (0.13–0.20) — never isotropic dilation; comp = `base + slope × column_width` clamped; push cutback 0.4 mm at open satin ends, 0.8 under a covering border. `phys`
- **25, 27, 28 (phys)** Registration drift is cumulative → border each element right after its fill, never a global outline pass. Density budget is a per-region sum `Σ(0.4/spacing)`; safe stack ≈2.5 units, never more than two full-density fills. Underlay costs 15–20% stitches but only 0.1–0.2 coverage units. `phys`
- **31, 34, 35 (phys)** Satin <1 mm → multi-ply run, >8 mm → split/fill. Caps: bottom-up, center-out, never section a cap-front fill, ≤57 mm height, extra comp over the seam. Small text: 4 mm satin floor, counters ≥0.8 mm, trims per word. `phys`
- **40, 41, 42, 43, 44 (fill)** Rows are level sets of a phase function — along-row density variation at fixed angle is **unrepresentable**. Coverage is additive in density, never spacing. A chord lies on the concave side (sagitta L²/8R) so endpoint containment tests miss it → cap stitch length by curvature `L ≤ √(8R·tol)`. Ring-to-ring transitions land under `MIN_STITCH_MM` → walk 1.0–1.5 mm along the ring while translating. `fill § Part 1`
- **45, 46, 47, 50, 51** A font's usable size range is set by its narrowest satin column, not legibility. **Cap height is the contract** — we measure the em (cap/em 0.58–0.98 across 22 fonts), and the UI asks for design width, so there is no way to request 6 mm letters. Satin valid on [1.5, 7] mm; 7 is a split trigger. Underlay is a ladder keyed to cap height (none <5, center run 6–10, edge run >10). A global min-stitch filter >0.5 mm eats small satin. `let`
- **53, 54, 55, 56, 57, 58** Short-stitch handling must be width-gated. Bold is a column-width term, pull comp a fabric term — ours are the same number (`WEIGHT_OFFSET_MM` added onto `pullCompMm`), and widening at constant spacing reads thin. Script joins are a metric (letter spacing 0%), not a generated connector, and auto-routing is the enemy of a joined font. A fit that silently leaves the band is worse than a refusal. `let`
- **59, 60** Gap distance is NOT the decision variable — the link rate is flat ~⅔ from 0 to 40 mm; links are routed to be **COVERED** (≥110 of 273 pass under something sewn later), not to be short. Our `trim_at_mm` 3.0–4.0 is the whole trims/1k gap. **They must ship together.** `chain`
- **§0 (spec)** One color stop = one human action. DST has no STOP opcode — every inter-layer break is a color change (`0xC3`); the writer must never merge adjacent same-color blocks, and the resequencer must never cross a step boundary. `spec § 0`

## Laws refuted or superseded

- **Law 7's interleave hedge is REFUTED.** Across 427 fill patches in 29 files the sew-order/geometric gap ratio is p10=med=p90=**1.0**; only 2/427 show an interleave signature. The doubt was also directionally backwards — an interleaved 0.20 reading would mean a true 0.10. Delete the hedge at `machine.py:39-40`. `l19 §1`, `r3` law 19
- **THE DANGEROUS ONE — law 19 "fills are 0.20 mm single-pass" is not one verdict, it is TWO POPULATIONS.** For the 29 freebie script/lettering files the 0.20 population is the **satin crossing half-step** of a 0.40–0.51 mm same-rail column (a normal 0.40 satin reads geo 0.20 / coverage 2.02 through a fill ruler); real 2-D area fills there run **0.28–1.00 mm at coverage ~1.0**, and our 0.40 sits inside it. For the 43 commissioned cap files it IS a real fill pitch (**0.161–0.193 mm**; traverse spans 6–54 mm, 3–17 penetrations per traverse — neither satin nor fan). `FILL_ROW_MM` stays **0.40**; the reason is that the question is unsettled, NOT that the law is refuted everywhere. `l19 §2, §8`
- **`l19 §7`'s proposed playbook restatement must NOT be applied as written** — it erases the cap population. `l19 §8`
- **`l19 §5.1` "the commissioned cap files are absent from the repo tree" was a search error**, not an absence: 43 DSTs live under `scratch_kent/Embroidery Files/`, hidden by `.gitignore:3` (`scratch_*`). `l19 §8`
- **"Kent's commissioned files contain ZERO tatami — cap logos are all satin" is FALSE.** The angle instrument's [0.55, 2.0] mm row-gap window structurally excludes every dense fill; two other round-3 instruments on the same bytes find a 1,373 mm² region at 0.177 and 1,084 mm² at 2.32. Laws 15–17 describe the LIGHT/sketch tier only; dense-fill angle is **unmeasured**. `r3 § Fill angle scope note`
- **"Engine satin is 2× sparser than the corpus" is refuted by a code read.** `stage6_satin` resamples at `ceil(len/SATIN_SPACING_MM)` with constant A,B rail order → same-rail 0.40. The 2× gap is real for FILL and imaginary for SATIN. `test_satin.py:231`'s `2*SATIN_SPACING_MM` samples `pts[0::4]`, asserting two stations. `r3` law 21 correction
- **Law 11 amended:** 1.40 mm was measured on closed loops/round letters. Real edge-covering borders are **1.66 mm** med (2.39 over the ≥20 mm subset). Two populations, two numbers. `r3` law 41
- **Law 12 refuted:** border density is **0.40**, identical to lettering — there is no density relaxation for riding over coverage. `r3` law 41
- **Centre-out sew order is actively backwards** (radial ρ med −0.50, 10 outside-in vs 2 centre-out); **largest-first is not a law** design-wide (8/4/5) or within a colour (47/23/30); **lettering-last is not a law** (0/7 in the last block, 3/7 in the first). `r3` laws 32, 35, 36
- **Law 31 (underlay hand-off) and law 38 (bare-fabric sliver) are NULLS** — 45.5/42.5 coin flip, and the one apparent gap is incidental adjacency. Do not implement either. `r3`
- **Round-3's own "42% of columns are bare" is wrong** — containment-based attribution; switching to spine COVERAGE moved "none" 42%→17%. `r3` law 26 limit
- **Both Law 17 charges against our engine are DISMISSED.** `SATIN_SHORT_STITCH_AT_MM = 0.3` measures bunching below design spacing, not the same-hole radius — 97–98% of our same-rail intervals land in 0.30–0.50 because that band is the target; raising it toward 0.5 would manufacture coverage holes. And `tie_run`'s 3-strike lock matches practice: the corpus is 9.455% multi-struck points, ours 9.8%, all 36 files contain 3+ stacks. `phys § Field note 2026-08-01`
- **The DT-first classifier swap is CLOSED, NEGATIVE.** Goldman's printed rule `2σ<μ<max/2` is unshippable — a uniform ribbon has μ≈max, so it sends 62 of 83 clean satins to fill (all-FN, the expensive direction). Corrected arms lose every satin/fill disagreement they create (junction max-spikes; variance term is resolution-sensitive within ~1% of its threshold). Survivors: M1 field hoist (merged) and the VP90 variance terms inside `is_satin_candidate`. `dtv §2, §5`; supersedes `dt §2` M2/M3
- **The one thing DT-first found — the missing width floor under satin — is itself DISPROVED for flat art.** 19/162 photo-class regions sew sub-millimetre satin (Law 31), but on 15 real customer logos 61 of 64 sub-1.0 mm satin shapes are ground the pro also satined. The reroute must be gated to the photo lane. `dtv §3.2`, `MASTER_SCOPE.md` live defect 2
- **`density_adjust` runs backwards on pile.** It *multiplies* row spacing, so `terry_towel = 1.1` yields 0.44 mm — 10% *less* dense on the substrate that needs +10–20%. To express +15% the multiplier must be ≈0.87. It also never reaches satin, which is the thing that sinks on pile. `spec §5.1, §5.2`
- **Wilcom's own "choose complementary spacing profiles" is a bug** — mirroring a spacing profile puts a **+33% coverage bulge at both ends** of every blend. The correct complement is hyperbolic `s_c = p/α_c`. `fill` law 41
- **Ink/Stitch's gradient accumulator is wrong** — forward Euler on `dy/di = s(y)` realizes an exponential, not linear, profile and lands the last rows 6.6% dense at a steep ramp. Use inverse-CDF `row_positions()`. We have the same latent bug: `_row_spans` anchors to each shape's own bbox, so abutting regions never aligned. `fill §3.1`
- **Law 52's fractional spacing does not apply today** — our arc is a rigid per-glyph rotation about the ink center, so glyph interiors are never bent and intra-glyph bunching does not occur. The real defect on tight radii is inter-glyph, and the fix is radius-aware letter spacing. Fractional spacing becomes mandatory only with envelopes. `let` law 52
- **Two of the lettering doc's four "corrections" are stale.** Mirror X/Y and the two-line circular badge both landed on `feat/satin-rails` in commit 2ffa28e and are real, tested primitives. The other two (no lettering underlay at all; `routeGlyph` never reads `opts.underlay`; `satinplay.centerRun` has zero callers) were re-verified TRUE. `let § Verification note`
- **Law 59 overturns the assumption the engine is built on** — trim-by-gap-distance. `chain`
- **Do not build the Voronoi route for contour fill**, do not use Jobard–Lefer streamlines for curved fill (realized spacing in [d_sep, 2d_sep], no cross-row correspondence → stagger impossible), and do not ship the (3,4) chamfer DT (5.41% measured error on a disc = 0.9 mm, larger than a stitch). `fill §1.1, §4.1`, `dt §5`
- **Melco US9702070B2 is LIVE to ~2029-2030** — do not implement its continuous-underlay graph traversal or duplicate-edge Euler tour as written. `dt §5.8`

## Unimplemented technique

- **Crosshatch** — a deliberate perpendicular second pass, present in 7 of 8 multi-fill designs (~46 of 153 overlapping pairs at 60–90°). Not built. `r3` law 17
- **Emitting one thread more than once** — ~56–60% of colour stops are returns to a thread already in the design (Fremont: 9 blocks, 4 threads, 5 returns; beckers: 5 blocks, 2 threads). `PlannedRegion.sew_index` is one index per thread; a lightness sort would collapse Fremont's 9 blocks into 4 and destroy the stack. **Architectural, not a constant.** `r3` law 34
- **Topological satin splits** at crossings (`SPLIT_SATIN_ABOVE_MM` splits by width only). `r3` law 30
- **Per-end class scoring** for entry (cap 3 / tee 2 / corner 1 / butt 1) and the 10/20 mm two-tier fade — only a binary free-end flag ships. `r3` law 27–29
- **Sketch/redwork tier** — whole designs of layered running-stitch passes; 5 corpus files yield zero satin columns. Nothing in our engine emits it. `play` law 10
- **The step/stop IR** — an ordered `steps[]` with a machine function plus an operator-action string per boundary. Five of eleven specialty techniques need it and none can ship without it. `spec §0`
- **Appliqué** (4 layers, offset chain, tolerance solver, partial-cover suppression, dieline SVG), **3D puff** (end-caps, density-normalized columns, underlay suppression, 5-stitch ties), **knockdown fill** (dilate + 45/135 angle pair), **bean/run variants**, **ITH flat patch**, **motif run**, **stipple/faux chenille**. `spec §1`
- **Lettering underlay of any kind** — `routeGlyph` is passed `opts.underlay` and never reads it; `satinplay.centerRun` has zero callers; the UI switch is inert. Law 50's ladder is built on a mechanism we do not have. `let § Corrections 4`
- **Ask for a letter height**, per-font size band enforcement, real sew field per placement (flat 200×200 for every placement, incl. `hat_front` where the Brother cap frame is 130×60), monogram mode, script-safe routing, split satin >7 mm, envelopes, mirror, character-count spacing, radius-aware arc spacing, width-gated short stitches, run-stitch mode below the satin floor. `let §2`
- **Contour fill, motif fill (Tier A pattern + Tier B lattice), density ramp, crossfade, curved/flow fill** — all four fill families beyond tatami. `fill`
- **Per-branch classification** (satin arms + filled body in one region) — flagged by Goldman's inventor, never claimed, no shipping product does it. Note `dtv` closed the *whole-shape* DT swap, not this. `dt §1.3, §2` M6
- **16-angle fragment minimization** for fill angle; **fixed vertices at shared borders** (`cfg.overlap_mm = 0.25` is currently paying partly for that defect). `dt §2` M5, M7

## Sequence claims

- **Underlay runs first**, `kind=UNDERLAY`, then the fill body. No emitter creates its own ties — `_apply_ties` owns them or they double. `fill § Part 0`
- **41/41 covering borders sew AFTER the fill they cover, 0/41 before.** `r3` law 40
- **Background-to-foreground, one sweep, outside-in.** Not largest-first, not centre-out. `r3` laws 32, 33
- **Border each element immediately after its fill** — never batch outlines as a final pass (registration drift). `phys` law 25
- **Caps: bottom-up, center-out, alternate over the seam, finish-as-you-go.** `PRECISION DRON HAT` sews bottom-to-top, which is why its three text lines are blocks 1–3 of 23. Center-out ships (`digitize.js:317`, `:637`); **bottom-up is not implemented and is the higher-value half** because it anchors against the stiff bill. `phys` law 34, `r3` law 35, `let §4.2`
- **Puff goes LAST, universally** — all flat sections first, because you are laying a physical slab. Stop code immediately before the puff colour is mandatory; end-caps sew **before** the top satin. Foam is torn away only after the puff colour completes. `spec §3.5, §3.9`
- **Knockdown is the FIRST block**, on its own colour stop. It **is** the underlay — turn conventional underlay off inside it. `spec §4`
- **Appliqué order:** placement → CC → (cutting line) → tackdown on the FULL closed contour → CC → cover. The trim happens **after** the tack, not between cutting line and tack — most hobby writeups get this wrong. Mode A (per-piece) is required whenever a later piece overlaps an earlier one; Mode B (batched) only when no piece overlaps. `spec §2.1, §2.11, §2.14`
- **Cover underlay, if enabled at all, sequences after the tackdown** — the tackdown *is* the underlay. `spec §2.8`
- **Where strokes cross, sequence so the stroke that stitches last sits on top.** `let §2b`
- **Keep a blend group adjacent in sew order**; stage 5 emits K regions with consecutive `sew_index`; pull comp applied once to the shared outline, not K times. `fill §3.4`
- **Contour fill: recurse into children before continuing the parent**; the thick fill path generates **backwards from the exit fragment**. `fill §1.2`, `dt §1.6`
- **Read card block 1 before building the motif router's start-point selection**, not after. `fill §5.5`
- **Laws 59 and 60 must ship together** — raising the link threshold without the coverage test converts trims into visible floats, strictly worse. `chain § Engine mapping`
- **Law 19's constant change must land with the preflight coverage change** — a 0.20 fill reads 2.00 coverage units at `COVERAGE_THREAD_W_MM = 0.40`, so any second layer crosses `COVERAGE_WARN_UNITS = 2.5` and a third hits `COVERAGE_BLOCK_UNITS`. `r3 § Engine mapping`
- **M1 before M2/M3; M6 before touching WO2005061774A1; items 1–2 of the fill build order before 4 and 6** (both consume `row_positions()`). Prototype the Wilcom T-junction frame before the clique machinery. `dt §2, §4.2`, `fill § Part 5`
