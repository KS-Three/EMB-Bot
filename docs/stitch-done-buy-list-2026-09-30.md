## 2. Attorney one-pager

**Proposed mark:** STITCH DONE (standard character). Also consider the
stylised form once the wordmark is settled.

**Goods and services to claim** (the attorney picks the wording):

- **Class 9** — downloadable software for converting images into
  machine-embroidery stitch files.
- **Class 42** — software as a service (SaaS) for embroidery digitizing;
  design of embroidery files.
- **Class 40** — custom embroidery digitizing services (covers the
  human-assisted lane, and it is where the embroidery incumbents file).

File **intent-to-use** now; the specimen follows at launch.

**What the search found** (Trademarkia; USPTO direct was not reachable
from the research environment, so the attorney's full-text search is the
one that counts):

- **No exact STITCH DONE / STITCHDONE** mark found, live or dead.
- **DONE** appears only in unrelated generics (gutters, oat milk,
  basketball camps).
- **STITCH neighbours, none confusable with a two-word imperative:**
  Stitch Fix (cl.45), Stitch Health (cl.9/42), CRS "Stitch" (cl.42).
  HP holds STITCH (cl.2/7) for inkjet textile printers — adjacent
  industry, different goods; it belongs in the brief because "stitch"
  plus textiles is HP's ground.
- **Common-law / market neighbours, not marks:** *Stitch AI*
  (stitchai.us, "AI Embroidery Digitizing in Seconds" — the same
  service, live); *Google Stitch* (stitch.withgoogle.com, AI design
  tool). Neither uses "Done". The attorney should assess whether Stitch
  AI has filed anything since this research.
- **Not the Nike frame.** "Stitch Done" is verb + adverb, not
  JUST-verb-IT; §I of the research doc has the JUST DO IT precedent list
  if the attorney wants it.

**Questions for the attorney:**

1. Is STITCH DONE registrable in cl.9/42 over the STITCH-formative marks
   above, or is "stitch" so diluted in this class that only the whole
   phrase is protectable? (We expect the latter and are fine with it.)
2. Does HP's STITCH (cl.2/7) reach a software mark for embroidery? We
   think no; we want it said.
3. File cl.40 now, or wait until the human-assisted lane ships?
4. Any state or common-law "Stitch Done" users in embroidery, sewing or
   quilting that a full search turns up? Our web search found none.

## 3. After the purchase — what changes in the product

Not started; Kent's call on timing. The rename touches, in order of
what a customer sees:

- The Studio's `<title>`, header wordmark, PWA name, and the "made with"
  line on exports.
- README and the public repo's description (repo name is a separate,
  bigger decision — redirects work, but every doc link changes).
- The landing page and the §C SEO plan, whose target phrases
  ("digitize image for embroidery", "convert to PES") do not depend on
  the name.

Until the domains are registered and the attorney has answered §2 Q1,
nothing public should carry the name.
