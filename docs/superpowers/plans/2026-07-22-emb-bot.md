# EMB Bot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a local, self-contained HTML tool that auto-digitizes an uploaded logo/photo or typed text into real machine-embroidery files (.DST primary, .EXP, .PES best-effort), sized to a chosen garment, with PNG/SVG export and a PDF stitch-out worksheet.

**Architecture:** Deterministic logic lives in dual-mode scripts under `src/` (each works both as a Node `require()` for tests and as a browser `<script src>`). Classic scripts load from `file://` without a build step, so `EMB-Bot.html` + `src/` double-clicks and runs. A shared stitch model (absolute points in 0.1 mm "DST units") is produced from color regions or glyph outlines, then fed to independent encoders and renderers.

**Tech Stack:** Vanilla JS (ES2020, no framework), Node 24 `node --test` for unit tests, opentype.js (font outlines) and jsPDF (PDF) loaded from CDN (jsDelivr) at runtime, HTML5 Canvas for rasterization/preview.

## Global Constraints

- Units: `MM_PER_INCH = 25.4`; DST unit = 0.1 mm, so `DST_UNITS_PER_MM = 10`. All stitch coordinates in the shared model are integer DST units, origin at design center, +X right, +Y **up**.
- Every `src/*.js` module MUST use the dual-mode footer so it loads in both Node and browser:
  ```js
  (function (root, factory) {
    const api = factory();
    if (typeof module !== "undefined" && module.exports) module.exports = api;
    root.EMB = Object.assign(root.EMB || {}, api);
  })(typeof globalThis !== "undefined" ? globalThis : this, function () {
    // ... define functions ...
    return { /* exported names */ };
  });
  ```
- Node tests use the built-in runner: files `test/*.test.js`, `const assert = require("node:assert")`, `const { test } = require("node:test")`, and `const { ... } = require("../src/xxx.js")`.
- Color regions interchange type (produced by image AND text pipelines, consumed by the model):
  `ColorRegion = { rgb: [r,g,b], polygons: Array<Array<{x:number,y:number}>> }` — coordinates in **pixels** (working raster space), outer + hole polygons mixed, filled by even-odd parity.
- Shared design type (produced by `buildDesign`, consumed by all encoders/renderers):
  `Design = { stitches: Array<{x:number,y:number,type:"stitch"|"jump"|"color"|"trim"|"end"}>, colors: Array<{r,g,b,name}>, widthMM:number, heightMM:number, stitchCount:number, colorCount:number }`.
- Output format dropdown DEFAULTS to `.DST`. PES is labeled best-effort in the UI.
- No secrets, no network calls except the two named CDNs. If a CDN fails to load, show a clear "check your internet connection" message; do not crash.

### Task 3: DST (Tajima) encoder — PRIMARY FORMAT

**Files:**
- Create: `src/dst.js`
- Test: `test/dst.test.js`

**Interfaces:**
- Consumes: nothing (operates on integer DST-unit deltas).
- Produces:
  - `encodeRecord(dx, dy, flag)` → `Uint8Array(3)`, `flag ∈ {"stitch","jump","color"}`, with `-121 ≤ dx,dy ≤ 121`.
  - `endRecord()` → `Uint8Array([0x00,0x00,0xF3])`.
  - `buildHeader(meta)` → `Uint8Array(512)` where meta `{ label, stitchCount, colorCount, xMin,xMax,yMin,yMax }`.
  - `encodeDST(design)` → `Uint8Array` full file. Walks `design.stitches` (absolute DST units), emits per-record deltas, auto-splitting any |delta|>121 into intermediate `jump` records, inserting color/jump/trim flags, ends with `endRecord`.

**DST record bit weights (authoritative — implementation MUST reproduce these):**

```
Byte0: x+1=0x80 x-1=0x40 x+9=0x20 x-9=0x10  y-9=0x08 y+9=0x04 y-1=0x02 y+1=0x01
Byte1: x+3=0x80 x-3=0x40 x+27=0x20 x-27=0x10 y-27=0x08 y+27=0x04 y-3=0x02 y+3=0x01
Byte2: (always +0x03) jump=0x80 color=0x40 x+81=0x20 x-81=0x10 y-81=0x08 y+81=0x04
```
Decompose dx and dy independently by greedily taking the largest signed weight (±81,±27,±9,±3,±1) whose magnitude ≤ remaining, OR-ing the matching bit into the right byte. Byte2 low bits `0x03` are ALWAYS set for stitch/jump/color; add `0x80` for jump, `0x40` for color.

**Header format:** ASCII field lines, each `KEY:value` terminated by `\r` (0x0D). Fields in order: `LA:`(label ≤16 chars), `ST:`(7-digit zero-padded stitch count), `CO:`(3-digit color count), `+X:`,`-X:`,`+Y:`,`-Y:` (5-digit extents), `AX:`,`AY:`,`MX:`,`MY:` (signed, value 0), `PD:******`. Concatenate, then pad with spaces (0x20) to exactly 512 bytes.
