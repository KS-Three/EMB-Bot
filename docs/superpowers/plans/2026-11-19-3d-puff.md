# 3D Puff for Uploaded Logos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A customer turns on 3D Puff on the review screen, puffs all eligible shapes or picks them, and gets a file whose puff shapes sew last as tack-down → foam stop → puff satin, with the stop printed on the worksheet.

**Architecture:** A new `stage6_puff.py` mirrors `stage6_applique.py`: a `puff_pass` pulls puff regions out of `planned` before the flat colour loop, and its operator-step blocks are appended after every other block. Step metadata finally reaches the Design dict (`plan_steps`), so the worksheet prints step actions for both puff and appliqué. The Studio sends `puff`/`puff_mode` as job config and `puff` as a per-shape override.

**Tech Stack:** Python 3.12 digitizer (pytest), Svelte Studio (vitest), JS engine worksheet (`node --test`).

**Spec:** `docs/superpowers/specs/2026-11-19-3d-puff-design.md` (approved by Kent 2026-11-19). Technique spec: `docs/specialty-techniques-2026-08-01.md` §3.

## Global Constraints

- **OFF is byte-identical.** `puff` defaults `False`; with it off the DST, the plan's blocks and the Design dict are unchanged from today.
- Every puff constant is a ROADMAP gate-1 physical constant: comment each `# unmeasured — §3; replace from TIRES HAT 3D` until Task 1 measures it. Never flip a default.
- Satin only; tatami never puffs. Puff blocks are never merged with neighbours (`block.step is not None`).
- Foam thickness fixed at 3 mm; worksheet text names it.
- Commands: digitizer `cd digitizer && .venv/Scripts/python -m pytest <path> -q` (Linux: `.venv/bin/python`); Studio `cd app && npx vitest run <file>`; engine `node --test <file>`. Never pipe pytest to `tail`.
- Edit files with the Edit tool, never a PowerShell regex round-trip (CLAUDE.md footgun 3).

## Review Focus

1. **Puff on, nothing eligible** (all shapes too thin, or all tatami-wide beyond 11 mm): no foam stop, no step blocks, one `PUFF_NONE_ELIGIBLE` warning; DST identical to OFF. → Task 4 `test_puff_on_nothing_eligible_is_off`.
2. **A puffed letter with counters** (an "O"): the closed-ends rule holds at the inner ring too, and the tack-down runs round both rings. → Task 3 `test_puff_counter_closed`.
3. **Re-digitize after picking shapes:** a per-shape `puff` survives merge/split and re-run. → Task 5 `test_puff_meta_carried`.
4. **Two puff threads:** two tack-downs, two foam stops, puff last for each, flat work all before. → Task 4 `test_puff_two_threads_two_stops`.
5. **Puff shape same thread as the flat shape sewn just before it:** not folded by `merge_adjacent_same_thread`. → Task 4 `test_puff_not_merged_with_flat`.
