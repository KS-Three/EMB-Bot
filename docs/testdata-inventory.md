# Test-data inventory

Every fixture under `digitizer/testdata/`, plus the app and engine test fixtures: what it exercises, what the repo records about where it came from, and which tests read it.

**This repo is public.** Nothing here adds artwork; this page only describes files already committed. Do not add client artwork, customer names, third-party stitch files or credentials without asking Kent (CLAUDE.md).

## How to read this

- **Used by** lists test files that name the fixture directly (`git grep -F <basename>` over `digitizer/tests`, `app/**/*.spec.js`, `app/e2e`, `test/*.js`). Fixtures that `conftest.py` loads (`logo_alpha`, `bg_uncertain`, `ribbon_curve`, and others) also reach every test requesting those pytest fixtures, so the list is a floor. “Tools only” means scripts under `digitizer/tools/` read it and no test does.
- **Provenance** is only what the repo records, with the source in parentheses. “No provenance recorded” means nothing I found states the origin; it is not a claim that the file is safe or unsafe.
- Compiled from a fresh grep on 2026-10-08 (main `ccf297d`). Re-run the grep before trusting a row after fixtures move.
- Not in git: `digitizer/testdata/photo/acceptance/*` is gitignored (its README is the one exception) and holds nothing committed. `digitizer/testdata/inbox/` is a staging area; files are meant to leave it once filed.
- A fixture is invisible to `tools/corpus_scorecard.py` until it is added to that script’s hardcoded `FIXTURES` list (`inbox/README.md`).

## Notes and loose ends

- **Duplicate:** `photo/drone_render.png` and `photo/logo_drone_thermal_badge.png` are byte-identical. Tools count it once (`blockcensus.py`, `stage0-signal-decision`), but `corpus_scorecard.py` FIXTURES carries both. Not changed here.
- **Unreferenced by any test:** `art/logo_mfab_hat.png`, `art/logo_toat_machine.png`, `photo/logo_drone_thermal_badge.png`, and most `reference/` stitch files (only `becker_chest_…lc_2_a.dst/.pes` and `becker_hat_polo_large_…logolc.dst` have a test; the rest are read by tools or by nothing).
- **Derived inputs are not artwork:** `reference/becker_*.jpg` are the vendor’s previews of the pro’s own stitches; digitizing them flatters the engine (`blockcensus.py` “INPUT PROVENANCE”).
- **Synthetic fixtures cannot recalibrate stage 0** (ROADMAP gate 2): they are printed but excluded from the margin.
- **Fonts under `test/fixtures/fonts/`** are CC-BY-SA-covered test fixtures pulled from the shipping library on 2026-08-04; do not move them back into `src/fonts/`.
- Licence grants for third-party stitch files and client logos are not recorded in the repo beyond Kent’s clearance notes above; this page does not settle them.
